# Agent icons

Replace the image in `<agent>/light` or `<agent>/dark` and rebuild Patchbay. Keep one image in each
folder. Use `icon.svg`, `icon.png`, or `icon.webp`. Select a transparent image for an icon without a
background.

For example, replace `codex/light/icon.png` to change the Codex icon in the light theme. The agent
folder uses the ID in its TOML definition.
